# Odin Recipes

## Description
This is the first project from The Odin Project's Foundations course. The project involves building a basic recipe website using only HTML. It serves as a practical exercise to demonstrate the ability to structure a webpage, link multiple pages together, and organize a project's directory.

## Skills Demonstrated
<<!-- how to code recipes 
By completing this project, I have successfully demonstrated the following skills:
* **HTML Structure:** Using semantic tags like `<h1>`, `<ul>`, `<ol>`, and `<li>`.
* **Linking & Navigation:** Creating internal links between the homepage and individual recipe pages.
* **Media Management:** Embedding and displaying images correctly using relative paths.
* **Project Organization:** Setting up a clean folder structure for assets and pages.
* **Git Workflow:** Practicing version control with professional commit messages.
<<!-- the  benefit of the project

By the end of this project, I will have demonstrated the ability to:
- Understand and follow project requirements
- Apply problem-solving and critical thinking skills
- Use relevant tools and technologies effectively

- Reflect on my learning process and identify areas for improvement
This project serves as both a learning experience and a demonstration of the skills I have developed throughout the course.
